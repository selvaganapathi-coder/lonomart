# Product Vision

Lonomart helps small businesses and individuals create and publish a professional website without coding, hosting, or design expertise.

## Core promise

Create and publish a useful professional website in approximately 3–5 minutes.

## Core workflow

1. Sign up
2. Create a website
3. Enter basic business information
4. Choose a template
5. Auto-populate the website
6. Customize structured content
7. Preview
8. Publish

## MVP boundary

The MVP focuses on template-based website creation, simple structured editing, preview, and fast publishing. Advanced visual editing, e-commerce, custom domains, collaboration, AI generation, and other roadmap capabilities are outside the initial scope.
