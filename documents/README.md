# Lonomart Documentation

Lonomart is currently in foundation bootstrap. The application is a Next.js App Router project with a minimal management-app provider boundary, a Prisma PostgreSQL schema file with no business tables, and Cloudflare/OpenNext configuration for future deployment validation.

Product principle: **Choose → Customize → Preview → Publish**.

Target outcome: enable a future 3–5 minute website creation flow without implementing business features in TASK-001.

## Sections

- `product/` records product direction and constraints.
- `architecture/` records implementation decisions and future boundaries.
- `testing/` records the smallest useful testing strategy.
- `tasks/` records backlog sequencing.
- `progress/` records current state, roadmap, and changelog.
