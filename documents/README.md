# Lonomart Engineering Documentation

This directory is the persistent engineering knowledge base for Lonomart.

## Product

Lonomart is a SaaS website creation and publishing platform focused on the workflow:

**Choose → Customize → Preview → Publish**

Target time to first published website: approximately 3–5 minutes.

## Current state

The repository is a fresh Next.js 16.3.1 application. TASK-001 establishes the technical foundation before business verticals are implemented.
